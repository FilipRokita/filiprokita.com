# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to
`contact@filiprokita.com` with what you found and how to reproduce it. I will
reply as soon as I can.

## Scope

This is a static site. It has no accounts, forms, database or server code, and it
stores nothing about visitors. Reports about the site's headers, its Content
Security Policy, its dependencies or this repository are welcome.

## Supported versions

Only the latest version on `main`, which is what the site serves.
